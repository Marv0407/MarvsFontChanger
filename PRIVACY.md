# Datenschutzerklärung – Marv's Font Changer

Zuletzt aktualisiert: September 2026

## Welche Daten werden verarbeitet?

- **Ausgewählte Schriftart und Schriftgröße pro Domain**: wird lokal im Browser gespeichert (`chrome.storage.local`), damit die Einstellung beim erneuten Besuch der Seite automatisch wiederhergestellt wird.
- **Namen der lokal installierten Schriftarten**: werden nur nach expliziter Zustimmung über den Browser-eigenen Berechtigungsdialog (Font Access API) ausgelesen und lokal gespeichert, um sie im Auswahlmenü der Erweiterung anzuzeigen.

## Was passiert NICHT?

- Es findet keine Übertragung von Daten an externe Server statt.
- Es werden keine Seiteninhalte gelesen oder gespeichert.
- Es wird kein Nutzungsverhalten getrackt oder an Dritte weitergegeben.
- Es werden keine Cookies gesetzt.
