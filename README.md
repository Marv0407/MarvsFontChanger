# Marv's Font Changer

Ändert Schriftart und Schriftgröße auf beliebigen Webseiten – für angenehmeres und barrierefreies Lesen im Browser.

## Funktionen

- Beliebige, auf dem Gerät installierte System-Schriftarten zur Auswahl
- Integrierte Schriftart [OpenDyslexic](https://opendyslexic.org/) zur Unterstützung beim Lesen für Menschen mit Legasthenie oder allgemeinen Leseschwierigkeiten
- Schriftgrößen-Regler, der alle Textgrößen gleichmäßig relativ zueinander skaliert – Überschriften bleiben größer als Fließtext
- Einstellungen werden pro Webseite gespeichert und automatisch wiederhergestellt
- Alle Daten bleiben lokal auf dem Gerät, keine Übertragung an externe Server

Marv's Font Changer speichert alle Einstellungen ausschließlich lokal im Browser (`chrome.storage.local`). Es findet keine Übertragung von Daten an externe Server statt. Für Details siehe [PRIVACY.md](./PRIVACY.md).
